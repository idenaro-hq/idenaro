Article 21(2)(g) requires entities to maintain basic cyber hygiene practices and cybersecurity training programmes. Cyber hygiene refers to the routine operational security practices that prevent common attacks - the security equivalent of regular maintenance.

A finding mapped to this article means the scanner detected an absence of controls that are widely considered baseline security practice and are expected to be in place regardless of an organisation's size or sector.

### What it means in practice

Basic hygiene findings include the absence of standard HTTP security headers (a baseline web hardening practice), missing Content Security Policy on authentication interfaces, exposed management endpoints that should be routinely disabled in production, and account lifecycle issues such as dormant accounts or missing offboarding controls. These are the controls that security awareness training programmes explicitly cover.

### Compliance obligation

- A defined set of baseline security controls must be applied to all production systems as a matter of routine.
- Account lifecycle management must include documented procedures for provisioning, review, and deprovisioning.
- Technical staff with access to identity infrastructure must receive regular cybersecurity training.
- Cyber hygiene checklists must be part of deployment sign-off processes.

### Enforcement context

Regulators use Art. 21(2)(g) findings to assess organisational security culture. Repeated absence of basic hygiene controls across multiple systems suggests a systemic training or process failure, which attracts higher penalties than isolated technical oversights.
